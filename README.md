# West — учебный проект по отслеживанию перспективных Twitter-аккаунтов

Этот репозиторий поможет шаг за шагом освоить базовый пайплайн: собрать свежие твиты, найти авторов с растущей популярностью и построить простой отчёт. Скрипты написаны максимально прозрачно, чтобы новичку было легче разобраться, а для тренировок есть офлайн-данные.

## 1. Что мы строим
* **Цель:** находить недавно «выстрелившие» аккаунты с небольшой аудиторией, но высокой вовлечённостью.
* **Что получится:** консольные скрипты для выгрузки данных из Twitter API и их агрегации, а также инструкции по развитию проекта.

## 2. Структура
```
West/
├── docs/                  # Подробные учебные инструкции
├── src/
│   ├── analysis/          # Скрипты аналитики (агрегация, рейтинги)
│   └── data_collection/   # Сбор данных из внешних источников
├── data/
│   ├── raw/               # Сырые выгрузки и учебные JSON-файлы
│   └── processed/         # Готовые CSV для аналитики
├── requirements.txt       # Список зависимостей
└── .env.example           # Пример конфигурации с переменными окружения
```

## 3. Подготовка окружения
1. Установите Python 3.10+.
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и добавьте `TWITTER_BEARER_TOKEN` (его можно получить через [Developer Portal](https://developer.twitter.com/en/portal/dashboard)). Если токена нет, используйте учебный режим (`--demo-data`).
4. При желании измените язык поиска через `DEFAULT_TWEET_LANGUAGE`.

## 4. Сбор данных
### 4.1 Учебный (офлайн) запуск
* Скрипт: `src/data_collection/collect_recent_accounts.py`.
* Демо-данные: `data/raw/sample_recent_tweets.json` (имитируют ответы Twitter API).
* Команда:
  ```bash
  python src/data_collection/collect_recent_accounts.py \
    --demo-data data/raw/sample_recent_tweets.json \
    --min-engagement 30 \
    --max-followers 6000
  ```
* Что произойдёт: из учебного JSON будут извлечены аккаунты с вовлечённостью ≥ 30, и результат сохранится в `data/processed/trending_accounts.csv`.

### 4.2 Боевой запуск с реальным API
* Основной скрипт: `src/data_collection/collect_recent_accounts.py`.
* Пример запуска:
  ```bash
  python src/data_collection/collect_recent_accounts.py \
    --query "startup" \
    --min-engagement 30 \
    --max-followers 8000 \
    --hours 12
  ```
* Что делает скрипт:
  1. Загружает свежие твиты из Twitter API (по умолчанию за последние 6 часов) или читает выбранный учебный JSON.
  2. Фильтрует авторов с количеством подписчиков меньше `--max-followers`.
  3. Сохраняет аккаунты, у которых суммарная вовлечённость ≥ `--min-engagement`, в CSV.

## 5. Аналитика
* Скрипт для агрегирования: `src/analysis/rank_accounts.py`.
* Пример запуска (объединить несколько выгрузок):
  ```bash
  python src/analysis/rank_accounts.py data/processed/trending_accounts*.csv
  ```
* Скрипт посчитает количество найденных твитов, среднюю и максимальную вовлечённость, затем сохранит топ-20 аккаунтов в `data/processed/ranked_accounts.csv`. Если входные файлы отсутствуют, программа подскажет, что нужно сначала собрать данные.
