# Как поддерживать локальную копию проекта в актуальном состоянии

Чтобы ваши изменения сохранялись и не терялись, а также чтобы получать свежие обновления из репозитория, придерживайтесь следующего рабочего процесса.

## 1. Настройте Git и клонируйте проект
1. Установите Git и выполните команду клонирования:
   ```powershell
   git clone https://github.com/<ваш-аккаунт>/<имя-репозитория>.git
   ```
2. Перейдите в папку проекта:
   ```powershell
   cd West
   ```
   Теперь эта папка связана с удалённым репозиторием и все изменения внутри можно отслеживать через Git.

## 2. Работайте в отдельной ветке
1. Перед началом новой задачи создайте ветку:
   ```powershell
   git checkout -b feature/my-task
   ```
2. Все изменения в файлах делайте внутри этой папки. Редактируйте скрипты через любимый редактор (VS Code, PyCharm, Notepad++ и т.д.) — Git автоматически заметит, что файл изменился.

## 3. Регулярно сохраняйте изменения (коммиты)
1. Просмотрите статус:
   ```powershell
   git status
   ```
2. Добавьте изменённые файлы и зафиксируйте коммит:
   ```powershell
   git add <путь-к-файлу>
   git commit -m "Короткое описание изменений"
   ```
   Коммит — снимок состояния файлов. Благодаря ему можно вернуться назад, если что-то сломается.

## 4. Получайте свежие обновления из удалённого репозитория
1. Перед началом работы и перед отправкой ваших коммитов забирайте обновления:
   ```powershell
   git fetch origin
   git pull --rebase origin main
   ```
   Это подтянет новые коммиты и аккуратно применит ваши изменения сверху.

## 5. Отправляйте свои изменения
1. Когда работа готова, отправьте ветку на сервер:
   ```powershell
   git push origin feature/my-task
   ```
2. На GitHub (или другой платформе) создайте Pull Request, чтобы поделиться результатом и получить обратную связь.

## 6. Синхронизируйте рабочие файлы между компьютерами
Если вы работаете на разных компьютерах, на каждом должен быть клон репозитория. Тогда процесс такой:
1. На первом компьютере сделайте коммиты и выполните `git push`.
2. На втором компьютере откройте ту же папку проекта и выполните `git pull`. Все изменения подтянутся автоматически.

## 7. Восстановление файлов, если что-то пошло не так
1. Чтобы вернуть файл к состоянию последнего коммита, используйте:
   ```powershell
   git checkout -- путь/к/файлу.py
   ```
2. Если нужно отменить локальные коммиты, выполните:
   ```powershell
   git reset --hard HEAD~1
   ```
   Будьте осторожны: команда стирает несохранённые изменения.

Следуя этим шагам, ваша локальная копия всегда будет синхронизирована с удалённым репозиторием, а все изменения — под контролем.
